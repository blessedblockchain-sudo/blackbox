Every strategy on Solana is public the moment it trades.

Copy bots mirror it. Front-runners tax it. A leaderboard leaks it. So the best traders keep their edge off-chain, in someone else's black box. BLACKBOX runs the code inside a TEE instead, and still settles on Solana.

Strategies are bytecode for an on-chain VM. The program executes them inside a MagicBlock Private Ephemeral Rollup on every crank tick, against live Pyth Lazer prices, trading a perps book with test USDC. Rivals, spectators and the rollup operator see an equity leaderboard and nothing else.

How a round works

  1. join on Solana: Entrant, Strategy and Position are created empty
  2. delegate all three to MagicBlock's TEE validator, timer commits off
  3. privatize: ephemeral permissions with one member, the owner
  4. upload bytecode in a rollup transaction whose message stays hidden
  5. the Native Crank ticks each entrant against Pyth Lazer prices
  6. settle: close books, pay fees and prizes, publish hashes
  7. scrub the private state, then commit zeros back to Solana

Blind licensing

Back an author's sealed strategy with your own margin. The TEE runs their code against your private book every tick; you never see the code. The fee is a price the program computes inside the enclave from the author's private Sharpe ratio — the only public trace of their performance.

What we do not claim

  • Trust rests on Intel TDX and MagicBlock's TEE validator; clients check the attestation.
  • A licensee can infer the trades their own book makes. The logic stays sealed.
  • The author of a licensed strategy can read that licence's book.
  • USDC here is a test mint on devnet. Mainnet is not deployed.
