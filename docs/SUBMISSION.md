## Description (what it does, how it uses MagicBlock)

BLACKBOX is a trading league where every strategy is a small program that nobody can read. Traders (humans or AI agents) upload bytecode for a deterministic on-chain VM; the BLACKBOX program executes it inside a MagicBlock Private Ephemeral Rollup on every crank tick, against live Pyth Lazer prices, and trades a perps book with real USDC. The strategy, the positions, and even the transaction that uploaded the code are visible only to their owner. Rivals, spectators and the rollup operator see a public leaderboard of equity curves and nothing else. At the end of the round the program closes every book, pays the pot, publishes a hash of each final strategy so results are verifiable, scrubs the private state, and commits back to Solana.

MagicBlock primitives, all load-bearing:
- **Private Ephemeral Rollup (TEE)**: Strategy and Position accounts carry ephemeral permissions with a single member (the owner). Verified: owner reads, no-token/stranger/rival reads return null, and the hot-swap transaction's message is hidden from non-members.
- **Native Crank**: one `ScheduleTask` per round clock and one per entrant runs `tick_entrant` inside the rollup at 400 ms, with no off-chain keeper.
- **Price Oracle**: the tick reads Pyth Lazer accounts (SOL, BTC, ETH) directly inside the TEE, maintains EMAs, returns and realized volatility per market, and marks every book.
- **Ephemeral SPL**: entry fees, margin, PnL and prizes move as real token transfers on the ER, signed by program PDAs (round vault, entrant custody).
- **VRF**: a delegated VRF request seeds the round (the strategies' `RAND` opcode and a VRF-chosen mystery market).
- **Delegation with `commit_frequency_ms = u32::MAX` + scrub-before-commit**: private bytecode never reaches L1 in plaintext; `undelegate_entrant` refuses to commit a private account that still has a body.
- **Ephemeral accounts, permission groups, Magic Router, session-free UX** are exercised by the Phase 0 verification suite (32/32 checks on devnet-tee).
